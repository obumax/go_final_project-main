# Todo-List Web Server (финальный проект курса "Go-разработчик" от Практикума)

## Описание проекта

Проект представляет собой веб-сервер Todo-List, оснащенный функциями планировщика задач, которые позволяют пользователям эффективно управлять своими задачами.

Функциональные возможности, которые предоставляет сервер:
* Вывод текущих задач;
* Автоматический рачет следующей даты для периодических задач;
* Добавление новых задач;
* Редактирование текущих задач;
* Удаление текущих задач;
* Возможность отмечать задачи как выполненные;
* Поиск задач по ключевым словам и конкретной дате;
* Возможность аутентификации путем использования JWT-токена.

## Выполнены все задания со звездочкой:

* Реализована возможность определять порт через переменную окружения TODO_PORT при запуске сервера;
* Реализована возможность определять путь к файлу базы данных через переменную окружения TODO_DBFILE при запуске сервера;
* Реализована логика правил повторения для вычисления следующих дат в случае недель и месяцев;
* Реализованы регистронезависимый поиск по ключевым словам и поиск по конкретной дате;
* Реализован механизм аутентификации путем использования JWT-токена;
* Создан Docker-образ для деплоя веб-сервера.

## Инструкция по запуску локально:

1. Убедитесь, что у вас установлен Go версии 1.24 или выше.

2. Установите зависимости:
```bash
go mod tidy
```

3. Создайте файл
.env
в корне проекта и добавьте в него следующие переменные:
```bash
TODO_PASSWORD=hey_Practicum!
TODO_DBFILE=scheduler.db
TODO_PORT=7540
```

4. Запустите сервер:
```bash
go run .
```

5. Откройте браузер и перейдите по адресу:
http://localhost:7540

## Инструкция по запуску тестов:

1. Получите токен, отправив запрос на
/api/signin
Например:
```bash
curl -X POST \
  http://localhost:7540/api/signin \
  -H 'Content-Type: application/json' \
  -d '{"username": "your_username", "password": "your_password"}'
  ```
Извлеките токен из ответа.

2. В файле
tests/settings.go
установите переменную
Token
со значением полученного токена.
```bash
Token = "ваш_токен"
```
Например:
```bash
Token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleHAiOjE3NTEwMTU5NjF9.wMOd_IDyLdMDOpyK-meYy0FPAgz60SNQzdeE6S29hIo"
```

3. Запустите тесты:
```bash
go test ./tests
```

## Инструкция по сборке и запуску проекта через Docker

1. Соберите Docker-образ:
```bash
docker build -t todo-web-server:1.0.0 .
```

2. Запустите контейнер:
```bash
docker run -d --name todo-web --env-file .env -p 7540:7540 -v $(pwd)/scheduler.db:/data/scheduler.db todo-web-server:1.0.0
```

3. Откройте браузер и перейдите по адресу:
http://localhost:7540

Значения переменных окружения .env файла, используемые при сборке:
TODO_PORT=7540
TODO_DBFILE=/data/scheduler.db
TODO_PASSWORD=hey_Practicum!
